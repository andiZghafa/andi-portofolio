1. Masalah yang Diselesaikan

Banyak mahasiswa sarjana menghadapi kebingungan saat memilih mata kuliah pilihan (elektif) dan merencanakan arah karir setelah lulus. Transkrip nilai sering kali hanya berupa daftar angka dan kode mata kuliah tanpa pemetaan yang jelas terhadap kebutuhan industri nyata (seperti persyaratan kompetensi software engineer, data analyst, atau machine learning engineer).

Gambar 1: Alur input transkrip akademik mahasiswa pada platform ASPIRE untuk menghasilkan rekomendasi karir dan mata kuliah berbasis LLM.

Bersama rekan saya, saya memimpin perancangan dan rekayasa platform ASPIRE. Sebagai Project Manager dan Full-Stack Lead, saya merancang arsitektur mulai dari modul parsing berkas transkrip nilai (PDF), orkestrasi prompt LLM untuk analisis celah kompetensi (skill gap analysis), hingga antarmuka rekomendasi berbasis Next.js.

2. Alur Pemrosesan Data & LLM Pipeline

Unggah Berkas Transkrip PDF Mahasiswa
    ↓
Server-Side PDF Parsing (Ekstraksi Nama MK, SKS, Nilai, & Kurikulum)
    ↓
Strukturisasi Profil Akademik (JSON Schema)
    ↓
LLM Gap Analysis & Reasoning Engine
    ├─ Mencocokkan riwayat nilai dengan matriks kompetensi industri
    ├─ Menemukan celah keahlian (missing competencies)
    └─ Memilih rekomendasi mata kuliah pilihan universitas yang relevan
    ↓
Dashboard Visual Interaktif (Next.js App Router + Tailwind)

3. Tumpukan Teknologi

Komponen Teknologi Peran Fungsional
Frontend & Routing Next.js 14 (App Router) + TypeScript Server Components, client interactivity, dan type-safety penuh.
Styling Tailwind CSS Desain antarmuka modern, responsif, dan mudah dipahami mahasiswa.
AI / LLM Engine LLM API Integration Analisis semantik transkrip akademik dan pembentukan jalur karir terpersonalisasi.
Penyimpanan Data MongoDB Penyimpanan dokumen profil mahasiswa, katalog mata kuliah, dan riwayat rekomendasi.
Hosting & CI/CD Vercel Deployment terotomatisasi dengan integrasi GitHub.

4. Kontribusi Rekayasa Utama

  • Manajemen Proyek & Sprint: Membagi tugas teknis frontend, backend, dan perancangan prompt LLM ke dalam timeline pengembangan terukur.
  • Pipeline Ekstraksi PDF: Mengatasi format transkrip nilai akademik yang tidak teratur agar dapat diubah menjadi data terstruktur yang konsisten.
  • Optimasi Prompt LLM: Merumuskan prompt terstruktur dengan keluaran JSON valid untuk mencegah halusinasi rekomendasi mata kuliah di luar kurikulum resmi.
  • Dokumentasi Manual: Menyusun manual teknis lengkap yang dapat diakses publik melalui repositori GitHub resmi.
