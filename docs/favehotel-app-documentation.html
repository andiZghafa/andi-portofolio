1. Masalah Operasional Hotel

Selama masa magang industri saya di FaveHotel Bogor, tim operasional housekeeping dan laundry masih mencatat keluar-masuk linen (sprei, handuk, sarung bantal) secara manual menggunakan buku log kertas. Metode konvensional ini sering menimbulkan masalah:

  • Selisih Stok & Kehilangan Kain: Sulit melacak apakah linen sedang dicuci di vendor eksternal, disimpan di gudang transit, atau sudah didistribusikan ke kamar.
  • Keterlambatan Laporan Manajemen: Rekapitulasi mingguan harus disalin ulang secara manual ke komputer, memakan waktu 4 - 6 jam kerja staf per minggu.
  • Pencatatan Rentan Rusak: Buku log fisik di area laundry lembab sering basah, sobek, atau tulisannya memudar sehingga menyulitkan audit akhir bulan.
Gambar 1A: Tampilan Web Housekeeping Logbook baru di Vercel (favehotellaundrylogbook.vercel.app) dengan 3 stasiun kerja terpisah dan ekspor Excel (.xlsx).
Gambar 1B: Antarmuka mobile floor untuk pemindaian QR linen langsung saat inspeksi kamar.

2. Pendekatan Rekayasa

Saya merancang dan membangun ekosistem aplikasi berbasis Flutter (Dart) yang mencakup aplikasi pemindai mobile di lantai kamar serta web portal terdedikasi untuk stasiun kerja housekeeping dan meja manajemen:

  • Pembaruan Antarmuka Web Housekeeping Logbook (Vercel): Versi web yang dideploy di favehotellaundrylogbook.vercel.app dirancang khusus untuk layar desktop dan tablet operasional. Antarmuka baru ini membagi alur kerja linen hotel ke dalam 3 stasiun kerja utama:
    • Fren Linen: Mengelola 8 item kain kamar standar (duvet cover, bedsheet, sarung bantal, handuk mandi, dan batik cloth).
    • Fast Items: Mengelola 6 perlengkapan kain spesifik (keset kaki/bath mat, mukena, sajadah, sarung, dan bendera hotel).
    • Rewash Station: Stasiun khusus untuk mengisolasi linen bernoda, robek, atau berstatus rewash agar tidak tercampur dengan kain bersih yang siap didistribusikan.
  • Ekspor Dokumen Excel Langsung (.xlsx): Dilengkapi tombol satu klik untuk mengekspor rekapitulasi mutasi linen langsung ke format .xlsx yang rapi untuk arsip akuntansi dan audit housekeeping tanpa pengolahan data manual.
  • Sinkronisasi Spreadsheet Dua Arah (Google Sheets API): Data pencatatan harian langsung tersimpan dan tersinkronisasi secara real-time ke spreadsheet cloud manajemen hotel tanpa memerlukan biaya sewa server basis data eksternal.
  • Repositori Kode Sumber Terbuka di GitHub: Seluruh kode sumber aplikasi web dipublikasikan secara terbuka di github.com/andiZghafa/Favehotel-LaundryApp untuk portofolio teknis dan dokumentasi arsitektur perangkat lunak.

4. Pengujian Lapangan & Pelatihan Staf

Seluruh siklus proyek saya kerjakan secara mandiri:

  • Melakukan wawancara langsung dengan kepala housekeeping dan staf laundry untuk memahami rute kerja mereka.
  • Menguji aplikasi secara langsung di lingkungan basah/lembab area binatu hotel.
  • Menyelenggarakan sesi pelatihan tatap muka (user training) untuk mengajarkan staf cara memindai QR dan membaca status stok.
  • Menulis dokumen panduan penggunaan lengkap dalam format PDF untuk SOP operasional hotel.
