1. Masalah Operasional Hotel

Selama masa magang industri saya di FaveHotel Bogor, tim operasional housekeeping dan laundry masih mencatat keluar-masuk linen (sprei, handuk, sarung bantal) secara manual menggunakan buku log kertas. Metode konvensional ini sering menimbulkan masalah:

  • Selisih Stok & Kehilangan Kain: Sulit melacak apakah linen sedang dicuci di vendor eksternal, disimpan di gudang transit, atau sudah didistribusikan ke kamar.
  • Keterlambatan Laporan Manajemen: Rekapitulasi mingguan harus disalin ulang secara manual ke komputer, memakan waktu 4 - 6 jam kerja staf per minggu.
  • Prosedur Penutupan Dapur (Kitchen Closing): Kurangnya checklist terstandarisasi untuk memastikan kebersihan, pemadaman kompor, dan penyimpanan bahan makanan beku sebelum staf pulang.
Gambar 1: Antarmuka aplikasi mobile FaveHotel (FREN) untuk pemindaian QR linen dan sinkronisasi spreadsheet operasional.

2. Pendekatan Rekayasa

Saya merancang dan membangun aplikasi berbasis Flutter (Dart) yang dapat dijalankan langsung pada ponsel Android staf operasional maupun diakses melalui browser:

  • Pemindai QR Kamera Berkecepatan Tinggi: Setiap keranjang dan kelompok linen diberi label stiker kode QR unik. Staf cukup mengarahkan kamera untuk mengidentifikasi batch barang dalam hitungan milidetik.
  • Sinkronisasi Spreadsheet Dua Arah (Google Sheets API): Untuk menghindari biaya sewa server basis data yang mahal, data mutasi stok langsung disinkronkan secara real-time ke spreadsheet cloud manajemen hotel. Manajemen dapat memantau grafik stok secara langsung tanpa konfigurasi server yang rumit.
  • Deployment Web (Vercel) & Android: Selain format APK mobile, aplikasi dikompilasi menjadi Flutter Web dan dideploy di Vercel pada domain favehotellaundrylogbook.vercel.app agar manajemen dapat mengecek stok dari laptop atau PC kantor.
  • Modul Checklist Penutupan Dapur: Validasi alur SOP kebersihan dapur dengan catatan waktu digital (timestamp) untuk mencegah kelalaian operasional.

3. Tumpukan Teknologi & Implementasi

Komponen Teknologi Fungsi Utama
Frontend Framework Flutter (Dart) Web & Mobile Aplikasi multiplatform yang responsif di HP Android staf dan browser desktop manajemen.
Web Hosting Vercel Edge Network Distribusi web app cepat dengan HTTPS otomatis di favehotellaundrylogbook.vercel.app.
Hardware Scanner Mobile Camera QR Reader Pemindaian barcode/QR batch linen di lorong hotel yang minim pencahayaan.
Penyimpanan Cloud Google Sheets API Integration Penyimpanan data cloud instan tanpa latensi dan tanpa biaya server backend.
Penyimpanan Lokal Local Cache (Offline Persistence) Menyimpan antrean data pindai sementara ketika koneksi Wi-Fi hotel terputus di area basement.

4. Pengujian Lapangan & Pelatihan Staf

Seluruh siklus proyek saya kerjakan secara mandiri:

  • Melakukan wawancara langsung dengan kepala housekeeping dan staf laundry untuk memahami rute kerja mereka.
  • Menguji aplikasi secara langsung di lingkungan basah/lembab area binatu hotel.
  • Menyelenggarakan sesi pelatihan tatap muka (user training) untuk mengajarkan staf cara memindai QR dan membaca status stok.
  • Menulis dokumen panduan penggunaan lengkap dalam format PDF untuk SOP operasional hotel.
