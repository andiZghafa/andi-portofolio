1. Latar Belakang & Tujuan Proyek

Museum Candi Prambanan menyimpan berbagai koleksi arkeologi bernilai sejarah tinggi, termasuk prasasti batu kuno (seperti Prasasti Siwagrha dan Prasasti Klurak), arca-arca candi, dan dokumentasi pemugaran kompleks Prambanan dari masa kolonial hingga modern.

Gambar 1: Antarmuka beranda resmi museumprambanan.twc.id dengan kurasi visual candi dan navigasi katalog digital.

Selama masa magang saya di unit IT Development PT Taman Wisata Candi, saya merombak antarmuka (UI) dan alur pengalaman pengguna (UX) portal museumprambanan.twc.id. Tujuannya adalah memperkuat kehadiran digital museum, menyediakan katalog artefak yang mudah diakses peneliti dan wisatawan, serta memberikan modul CMS bagi kurator museum untuk memperbarui informasi koleksi secara mandiri.

2. Modul Utama Sistem

  • Katalog Digital Koleksi Arkeologi: Menampilkan foto resolusi tinggi, transliterasi prasasti, konteks sejarah penemuan, serta lokasi situs candi asal (Candi Sewu, Candi Bubrah, Candi Lumbung, Candi Prambanan).
  • Pelacak Kunjungan Real-Time (Visitor Counter): Modul pencatat metrik kunjungan harian yang terintegrasi untuk memantau trafik pengunjung situs web.
  • Curator Content Management System (CMS): Panel admin terproteksi bagi tim edukasi dan kurator museum untuk menambahkan artefak baru, mengedit narasi sejarah, dan memperbarui jadwal pameran khusus.
  • Performa & Responsivitas Mobile: Mengingat sebagian besar wisatawan mengakses portal melalui perangkat seluler saat berada di kawasan candi, tata letak dioptimalkan dengan aset gambar terkompresi dan interaksi bebas lag.

3. Arsitektur & Tumpukan Teknologi

Layer Teknologi Peran Teknis
Backend Framework Laravel & PHP 8.3 Routing publik, manajemen sesi kurator, autentikasi aman, dan pengolahan data katalog.
Frontend Templating Blade Components Server-side rendering (SSR) modular untuk kecepatan load awal (First Contentful Paint) optimal.
Styling & Desain Tailwind CSS Tipografi hierarkis, desain responsif multi-perangkat, dan palet visual selaras warisan budaya.
Asset Bundler Vite Kompilasi CSS/JS ringkas untuk meminimalkan beban bandwidth wisatawan di lapangan.
Database MySQL Penyimpanan relasional artefak, kategori era sejarah, metadata media, dan log kunjungan.

4. Hasil & Dampak Lapangan

Platform telah terpasang dan berjalan langsung (live production) di bawah domain museumprambanan.twc.id. Pembaruan ini memudahkan kurator museum mempublikasikan temuan arkeologi baru tanpa harus menunggu modifikasi kode dari pihak vendor luar, sekaligus menjadi pintu gerbang edukasi bagi wisatawan sebelum dan sesudah mengunjungi situs fisik Candi Prambanan.
