1. Tujuan Proyek & Prinsip Desain OOP

Proyek ini dirancang untuk mendemonstrasikan implementasi mendalam dari prinsip-prinsip Pemrograman Berorientasi Objek (Object-Oriented Programming / OOP) dan struktur data efisien dalam bahasa pemrograman Java:

Gambar 1: Struktur menu konsol CLI berbasis teks dengan pembagian wewenang hak akses peran pengguna (RBAC).
  • Enkapsulasi (Encapsulation): Memproteksi state objek internal (seperti status peminjaman, saldo denda, dan hak akses akun) melalui getter/setter dan access modifier ketat.
  • Pewarisan (Inheritance): Hierarki kelas pengguna turunan (AdminUser dan GuestUser yang mewarisi kelas abstrak User).
  • Polimorfisme (Polymorphism): Penanganan operasi pencarian buku dan pemrosesan transaksi melalui antarmuka (interfaces) dan overriding metode yang fleksibel.
  • Abstraksi (Abstraction): Pemisahan layer penyimpanan data koleksi pustaka dari logika presentasi berbasis Command Line Interface (CLI).

2. Fitur Sistem & Role-Based Access Control (RBAC)

Peran Pengguna Hak Akses & Wewenang Operasional
Administrator Menambah katalog buku baru, memperbarui stok eksemplar, menghapus data buku usang, melihat buku catatan transaksi seluruh peminjam, dan mencatat denda keterlambatan.
Guest / Member Mencari koleksi buku berdasarkan judul, pengarang, nomor ISBN, atau kategori genre, memeriksa ketersediaan stok buku fisik, dan mengajukan peminjaman mandiri.

3. Validasi Transaksi & Penanganan Eksepsi

Untuk mencegah inkonsistensi data buku dan korupsi memori selama runtime konsol:

  • Sanitasi Input Pengguna: Memeriksa tipe data input teks dan angka menggunakan blok try-catch untuk mencegah program crash akibat InputMismatchException.
  • Validasi Stok Real-Time: Sistem otomatis menolak transaksi peminjaman jika stok eksemplar buku bernilai 0 (nol).
  • Kalkulasi Batas Waktu Pinjam: Penghitungan tanggal jatuh tempo peminjaman dan kalkulasi otomatis penalti denda harian jika buku dikembalikan melewati batas waktu.
